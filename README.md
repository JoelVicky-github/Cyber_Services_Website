# Cyber Services Homepage

A simple static homepage built with HTML5 and CSS3 as an early web development practice project.

## Overview

This repository contains a basic website homepage created while learning frontend fundamentals. The goal was to practice structuring a webpage and applying CSS styling to create a clean, presentable layout.

## What I Practiced

- HTML5 semantic structure
- CSS layout and styling
- Typography and spacing
- Building a complete page from scratch

## Technologies Used

- **HTML5** — page structure
- **CSS3** — visual styling

## How to Run / View

Simply open the main HTML file in your browser:

```bash
# No installation needed
open index.html
```

## Project Goals

- Understand basic webpage structure
- Practice CSS styling techniques
- Build confidence with frontend fundamentals

## Status

Early learning project.  
This was one of the first complete webpages I built while studying HTML and CSS.

## Future Direction

Moving toward more practical projects that combine backend logic, automation, and AI tools rather than static pages only.
